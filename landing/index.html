    FAQ

    How do I get started with pool-anything?

    Install, run the dev server, open :3000, search your provider, paste keys, and send one request through /proxy. The docs walk the whole loop.

    What kind of keys can I pool?

    Any provider in the 36-row registry, plus custom via base_url, key header, and prefix. Each pool holds keys for one provider.

    How does rotation work with my existing code?

    Point your HTTP client at /api/pools/:id/proxy instead of the upstream. The pool picks cursor % keys.length, injects the key, forwards, and records usage.

    Is it a proxy or a manager?

    Both. Manage keys in the UI or API key manager, then proxy live traffic through the same pools with per-key receipts.

    What are the system requirements?

    Node 22+ for built-in SQLite and fetch. No runtime npm dependencies, one local .db file.

    How much usage can it track?

    Every proxy or consume call appends a usage row with tokens. /usage rolls it up per key and pool with quota math where known.

    Does it work with custom endpoints?

    Yes — create a pool with your own base_url, key_header (or query:param), and key_prefix. Provider extras merge automatically.

    Where do keys live?

    In data/pool-anything.db on your machine, plaintext, gitignored. Lists return masked values only; keep the API on localhost or behind your gate.

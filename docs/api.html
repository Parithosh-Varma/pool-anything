HTTP API

Everything the web UI can do, as a plain JSON API. Base URL: http://localhost:3000

Conventions

  • All request bodies are JSON (content-type: application/json); all responses are JSON unless noted.
  • Errors are { "error": "…" } with a 4xx/5xx status.
  • List endpoints mask keys (gsk_…ab). Only GET /keys/:id returns the full key.
  • The API is unauthenticated — run it on localhost or behind your own auth.
  • :id in pool paths is the pool id; :keyId is a key id.

Providers

GET/api/providers

All known providers from data/providers.json.

[

Pools

GET/api/pools

List all pools, newest first. Each row: id, provider, name, cursor, base_url, key_header, key_prefix, created_at.

POST/api/pools

Create a pool.

{ "provider": "groq", "name": "groq pool",
  "base_url": "", "key_header": "", "key_prefix": "" }
# → 200 { "id": 1, "provider": "groq", "name": "groq pool", "cursor": 0, … }

provider and name are required. The optional base_url / key_header / key_prefix override the registry values (useful for custom providers; empty means “use the registry”).

GET/api/pools/:id

Pool summary with usage.

{ "id": 1, "provider": "groq", "cursor": 12, "keys": 3, "used": 1520,
  "quota": null, "remaining": null,
  "perKey": [ { "id": 1, "label": "key 1", "used": 520 }, … ] }

quota / remaining are null unless the provider has a known token quota (currently Cartesia: 20000).

DELETE/api/pools/:id

Delete the pool, its keys and its usage records.

Rotation

GET/api/pools/:id/next

Return the next key (masked) and advance the cursor.

{ "key_id": 2, "label": "key 2", "masked": "gsk_…9f", "info": "" }

400 { "error": "pool has no keys" } · 404 { "error": "pool not found" }

POST/api/pools/:id/consume

Rotate to the next key and record usage against it.

{ "tokens": 250 }
# → { "key_id": 2, "label": "key 2", "masked": "gsk_…9f", "info": "", "tokens": 250 }

tokens must be a positive integer.

GET/api/pools/:id/usage

Usage rollup for the pool.

{ "pool_id": 1, "used": 1520, "quota": null, "remaining": null,
  "perKey": [ { "id": 1, "label": "key 1", "used": 520 }, … ] }

Proxy

POST/api/pools/:id/proxy

The main event: pick the next key, inject its credentials, forward the request to the provider, record usage, and report back.

{ "path": "/chat/completions",     // appended to the pool's base URL
  "method": "POST",               // optional, defaults to POST
  "body": { "…": "…" },           // optional, JSON-encoded upstream
  "headers": { "x-custom": "v" }, // optional extra headers
  "tokens": 24 }                  // optional, recorded as usage
curl -X POST http://localhost:3000/api/pools/1/proxy \
  -H 'content-type: application/json' \
  -d '{"path":"/openai/v1/models","method":"GET"}'

Response:

{ "key_id": 2, "label": "key 2", "masked": "gsk_…9f",
  "status": 200, "body": "…" }   // body truncated to 4000 chars

How the key is injected, based on the provider's keyHeader:

keyHeader shapeInjectionExamples
Authorization + prefixHeader Authorization: Bearer <key>Groq, OpenAI, OpenRouter, Cohere…
Plain name + prefixHeader <name><prefix><key>x-api-key (Anthropic), xi-api-key (ElevenLabs), Token (Deepgram)
query:<param>Appended as ?<param>=<key>query:access_token (Mapbox), query:key (Google Maps), query:appid (OpenWeather)

Provider-specific extras (e.g. anthropic-version, Cartesia-Version) are merged in automatically. On network failure you get 502 { "error": "upstream unreachable", "detail": … }. If the pool has no base URL (custom provider): 400 { "error": "pool has no base_url …" }.

Keys

GET/api/pools/:id/keys

List keys — masked, never the raw value.

[ { "id": 1, "label": "key 1", "masked": "gsk_…ab", "info": "", "created_at": "…" } ]
POST/api/pools/:id/keys

Add a key. { "label": "key 1", "api_key": "gsk_…", "info": "optional note" } → 200 { "id": 7 }

GET/api/pools/:id/keys/:keyId

Fetch a single key in full (powers the UI's View button).

{ "id": 1, "label": "key 1", "api_key": "gsk_actual_key…", "info": "", "masked": "gsk_…ab" }
PATCH/api/pools/:id/keys/:keyId

Update any of label, api_key, info (omitted fields stay unchanged; empty api_key is rejected).

{ "label": "key 1 — team B", "api_key": "gsk_new…" }
DELETE/api/pools/:id/keys/:keyId

Remove a key from the pool → { "ok": true }.

Getting started

From clone to a working pooled proxy in under five minutes.

Requirements

  • Node.js ≥ 22 — the app uses the built-in node:sqlite module and native fetch.
  • API keys for whichever provider you want to pool.
  • That's it — there are no runtime npm dependencies.

Run it

npm install     # dev deps only (tsx, typescript)
npm run dev     # starts http://localhost:3000 with reload

Verify it's up:

curl http://localhost:3000/health
# ok

curl http://localhost:3000/api/db/ping
# {"ok":true,"path":"…/data/pool-anything.db","items":0}

Create your first pool

  1. Open http://localhost:3000 and search a provider (e.g. “groq”) in the search box.
  2. Click it. The setup dialog creates a pool for that provider automatically.
  3. Paste an API key into the input and press Enter (or click Gather). Repeat for every key you own — key 1, key 2, …
  4. Press Done. Your pool now shows up on the Pools page and in the API key manager, where you can view, edit or remove individual keys.
  5. Send a request through the pool — see the proxy endpoint:
curl -X POST http://localhost:3000/api/pools/1/proxy \
  -H 'content-type: application/json' \
  -d '{"path":"/openai/v1/models","method":"GET"}'
Tip: every proxy call rotates to the next key and returns key_id / label, so you can watch keys take turns. Add "tokens": N to record usage against that key.

Sandbox

The sandbox is a stripped-down copy of the API bound to 127.0.0.1 for testing pools without touching the main UI:

npm run sandbox
open http://127.0.0.1:4000/ui

It shares the same database and endpoints — pick a provider tab, gather keys, then use Next (rotate), Usage and Send via pool to exercise rotation.

Production build: run npm run build then npm run start:dist from the project root — the server reads data/providers.json, public/logos/ and src/logo.png relative to the working directory.
